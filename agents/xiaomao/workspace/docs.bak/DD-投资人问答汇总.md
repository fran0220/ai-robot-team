## 🎯 核心问答速查

### 硬件选型
**Q: 为什么选择 RK3587？**
- 算力匹配（≥6 TOPS NPU）
- 外设丰富，生态成熟
- 成本/功耗平衡
- 备选：JH7203（国产化）、RK3588

### 架构设计
**Q: 为什么双机协同而不是一体机？**
- 职责清晰，降低耦合
- 模块化扩展（象棋、教育等）
- 独立维护升级
- 成本：初期略高，长期TCO更优

### 关键技术指标
| 指标 | 目标 | 保障方案 |
|------|------|----------|
| 棋子识别准确率 | ≥99.5% | 深度学习+几何校正+光照控制 |
| 落子精度 | ≤±1.0mm | 闭环控制+视觉校正+补偿算法 |
| 语音唤醒延迟 | ≤300ms | 本地轻量ASR |
| AI推理延迟 | ≤50ms | INT8量化，模型≤10MB |

### 竞品对比
**主要竞品**：SenseRobot Go / 元萝卜
**我们的差异化**：
1. 双机协同架构（vs 一体机）
2. 模块化扩展能力
3. 监考/反作弊场景闭环
4. 围棋模块不堆算力，成本可控

### 技术壁垒
1. **端侧AI优化**：针对NPU的量化/裁剪
2. **视觉+机械协同**：光照适应、材质兼容
3. **监考系统**：多维检测、证据链闭环
4. **数据闭环**：教学/对弈/异常棋谱持续优化

### BOM估算
- 主控机器人：¥1,500–2,200
- 围棋模块：¥1,800–2,800
- **整机**：¥3,300–5,000（视配置档位）

### 量产风险
- 机械臂精度一致性
- 视觉识别环境适应性
- 供应链稳定性
- 预计量产准备：4-6个月
