# 围棋机器人竞品硬件方案对比

## 调研目标
- 识别主流围棋机器人/实体智能围棋盘竞品
- 汇总其硬件方案与关键参数公开信息
- 对比我方差异化与成本优势/劣势

## 竞品概览（扩充样本）

### 1) SenseRobot Go（SenseTime）
- **形态**：带机械臂的实体围棋机器人（棋盘+机械臂+视觉+App）
- **公开卖点/功能**：机械臂落子、视觉识别、AI对弈/练习、线上对战、App复盘
- **硬件线索**：官方强调“Robotic Arm + Visual Perception + Hand-Eye Coordination”，视觉识别精度宣传达到 99.9%（官方宣称）
- **价格区间**：官网/电商页显示售价约 $999（标价，非批量）
- **来源**：
  - SenseTime 官方发布会新闻（官方公布）: https://www.sensetime.com/en/news-detail/51166774?categoryId=1072
  - SenseRobot Go 商店页（官方公布，含 99.9% 识别率宣传/售价）: https://www.senserobotchess.com/products/senserobot-ai-go-robot

### 2) Go Professional / Sense Robot Go Professional（电商渠道）
- **形态**：带机械臂的智能围棋盘
- **公开卖点/功能**：机械臂落子 + 视觉识别；宣传“~1mm 落子精度 / 99.9% 识别率 / 3-DOF 机械臂”（官方宣称，电商口径）
- **硬件线索**：更偏消费级产品文案，细节参数有限（可能与 SenseRobot 系列同源或代理）
- **价格区间**：电商渠道零售售价（非批量）
- **来源**：
  - Amazon 商品页（官方公布/电商信息）: https://www.amazon.com/Sense-Robot-Go-Professional-Real-Time/dp/B0F2FHGYLX

### 3) IZIS AI Baduk Board（湖南隐智科技）
- **形态**：实体智能围棋盘（无机械臂），内置传感识别 + 连接云端AI
- **公开卖点/功能**：自动记录对局、AI分析、云端棋谱、在线对弈、实体棋盘触感
- **硬件线索**：公开参数含尺寸、重量、5V供电、USB接口等；材质为ABS
- **价格区间**：海外电商销售（具体价格随渠道变化）

  - 海外零售渠道汇总功能描述（评测媒体/电商）: https://store.baduk.club/products/izis-ai-baduk-board

### 4) 晨光智能棋盘 APK959X7（智能棋盘，无机械臂）

- **硬件线索**：面向消费级娱乐/教学，强调离线模式与题库

### 5) 纯软件/云端棋力产品（KataGo + 前端/云服务）
- **形态**：纯软件/云端AI（无实体棋盘与机械臂）
- **硬件差异**：主要依赖通用算力（PC/云端GPU），不提供实体落子/硬件交互
- **公开卖点/功能**：超强棋力、开源、可接入多种GUI/云服务
- **价格区间**：软件本身免费；算力成本由用户/平台承担

## 我方技术差异化（建议对外说法）
- **强调机械臂落子稳定性与精度**：与仅“智能棋盘”类产品相比，提供更接近“真人对弈”的体验。
- **强调端侧 AI + 低时延交互**：相比云端依赖，端侧推理降低延迟、提升隐私与稳定性（需与架构一致）。
- **强调系统级协同**：感知（视觉/传感）+控制（机械臂）+AI引擎整体优化（若已有协同方案）。

## 成本优势/劣势分析（基于公开信息的推测，分析假设）
- **优势点**：
  - 相对 SenseRobot 等高价位产品，如能做到“等体验但低 BOM / 低售价”，可强调性价比（分析假设）。
  - 机械臂方案若采用轻量化结构+标准器件，有望降低机械/装配成本（分析假设）。
- **劣势点**：
  - 机械臂+视觉方案天然成本高于“仅智能棋盘”类竞品（传感+主控）（分析假设）。
  - 市场教育成本高，需证明可靠性/寿命/维护成本（分析假设）。

## 风险与不确定性
- 多数竞品公开参数是市场宣传口径，**缺乏完整BOM或拆解数据**。
- 电商渠道产品可能存在代工/品牌混淆，**硬件来源不透明**。
- 精度/识别率等指标缺乏第三方验证。
