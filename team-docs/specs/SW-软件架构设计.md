# 软件架构设计

## 1. 总体架构
系统采用“主控机器人 + 围棋模块”双机协同架构，分层如下：
1. 硬件层：主控板、传感器、摄像头、执行机构。
2. 驱动层：音频、摄像头、运动控制、触摸驱动。
3. 中间件层：设备管理、消息总线、日志、配置管理。
4. 服务层：语音交互、情感识别、围棋 AI、视觉识别、机械控制。
5. 应用层：对弈、教学、考级监考、陪伴对话。

## 2. 核心模块
### 2.1 语音交互模块
- 唤醒词检测、本地 ASR + 云端增强。
- NLU 语义解析与上下文管理。
- TTS 输出与情绪韵律控制。

### 2.2 情感识别/表达模块
- 语音情绪识别 + 触摸输入。
- 情绪状态机驱动表情屏/灯效/动作。
- 个性化情感模型与偏好记忆。

### 2.3 围棋 AI 模块
- 本地棋力引擎（KataGo/自研）。
- 难度分级、胜率分析、候选点推荐。
- 教学模式（定式、死活题、复盘）。

### 2.4 视觉识别模块
- 棋盘识别、棋子检测、局面跟踪。
- 几何校正、光照自适应。
- 状态同步与异常恢复。

### 2.5 机械控制模块
- 轨迹规划、碰撞检测、末端吸附/夹持控制。
- 安全控制：限位、急停、力矩保护。

## 3. 系统通信
- 主控 ↔ 围棋模块：Wi‑Fi / USB‑C / BLE。
- 通信方式：REST + gRPC，必要状态使用 MQTT 消息总线。
- 时延要求：关键交互 < 50ms。

## 4. 数据与存储
- 棋谱：SGF 格式。
- 日志：JSON Lines，上传云端或本地存储。
- 模型：ONNX/TensorRT 格式，支持版本化管理。

## 5. 安全与隐私
- 数据最小化采集，关键数据本地处理。
- 传输加密：TLS 1.3。
- 权限隔离与系统日志审计。
