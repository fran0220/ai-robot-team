# 围棋模块硬件规格（GBM-19）

## 1. 机械臂
- 自由度：4–6 轴。
- 运动行程：
  - X/Y 行程 ≥ 450mm（覆盖 19×19 棋盘）。
  - Z 行程 ≥ 60mm（提子/落子高度）。
- 重复精度：≤ ±0.5mm。
- 末端工具：吸盘或软夹爪，带压力/真空检测。
- 速度：单次落子 ≤ 4s，具速度/加速度可调能力。

## 2. 棋盘
- 尺寸：19×19 标准棋盘，线距 22mm。
- 材质：哑光防反射材质（木质或高强度树脂）。
- 识别方式：
  - 视觉识别（RGB 摄像头 + 几何校正）。
  - 预置标定标识（四角或隐藏标记）。

## 3. 棋子
- 材质：环保树脂或仿玉材料。
- 颜色：标准黑白双套。
- 规格：直径 22mm，厚度 6–7mm。
- 存储：
  - 侧边收纳仓。
  - 漏斗式供子/可更换棋罐。

## 4. 摄像头与光学
- 摄像头：1080p RGB 广角，≥ 120° 覆盖。
- 补光：棋盘周边 LED 补光，色温 4000–5000K。
- 成像要求：支持 100–2000 lux 光照范围。

## 5. 通信与控制
- 与主机通信：Wi‑Fi / USB-C / BLE（可选）。
- 运动控制：实时控制器 + 分布式驱动，支持轨迹规划。

## 6. 外壳与安全
- 机械臂全包覆或半包覆，避免夹手。
- 棋盘边缘圆角处理，防儿童磕碰。
- 具急停按钮与限位保护。

## 7. 供电
- 外接适配器供电为主，DC 24V/5A（建议值）。
- 具过流/过温保护与保险。
