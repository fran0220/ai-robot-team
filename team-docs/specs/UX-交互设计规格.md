# 交互设计规格（儿童友好）

## 1. 语音交互流程
1. 唤醒词触发（本地唤醒 <300ms）。
2. 语音输入识别（ASR <1.5s）。
3. NLU 理解与意图识别。
4. 回复生成 + TTS 播放。
5. 动作/灯效联动。

## 2. 情感状态机
- 开心：亮色动画 + 轻快语调。
- 难过：低亮度 + 缓慢动画。
- 思考：蓝色呼吸灯 + “思考中”表情。
- 鼓励：金色渐变 + 赞许语调。
- 生气（可选）：红色闪烁 + 提示语。

## 3. 围棋交互流程
1. 进入围棋模式（语音/触摸切换）。
2. 选择难度与对局模式（对弈/教学/复盘）。
3. 棋盘识别完成 → 机器人语音确认。
4. 用户落子 → 视觉识别 → AI 决策。
5. 机械臂落子 → 语音播报。
6. 对局结束 → 复盘/学习建议。

## 4. 儿童友好 UI/UX 原则
- 大按钮、少步骤、低认知负担。
- 语音优先，必要时屏幕辅助手势提示。
- 状态清晰：灯效 + 表情 + 语音三重反馈。
- 正向激励：更多鼓励语言，减少否定表达。
- 安全提示：机械臂动作前语音提醒，避免意外接触。
