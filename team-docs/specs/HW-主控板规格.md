# 主控板规格（RK3587）

## 1. 设计目标
- 适配情感交互与多模态感知场景，支持本地语音与视觉推理。
- 提供完整外设接口，满足表情屏、灯效、音频、触摸与扩展模块需求。

## 2. 处理器与存储
- SoC：RK3587（4×A76 + 4×A55），NPU ≥ 6 TOPS。
- 内存：LPDDR4X/LPDDR5，容量 8–16GB。
- 存储：eMMC 64–128GB。
- 扩展存储：M.2 NVMe（可选），microSD 调试位（可选）。

## 3. 显示与图形
- 显示接口：MIPI-DSI（1 路），支持 800×480 ~ 1280×720。
- 图形能力：支持 2D/3D 图形加速，支持 UI 动画和表情渲染。

## 4. 视觉与摄像头
- 摄像头接口：MIPI-CSI 2 路，支持 1080p30 双路输入。
- 推荐摄像头：广角 RGB（情感识别与姿态分析）。
- 预留接口：TOF/深度摄像头（可选）。

## 5. 音频子系统
- 音频接口：I2S（2 路），支持外置功放与麦克风阵列。
- 录音：2–4 麦克风阵列，支持回声消除与降噪。
- 播放：2×2W 或 1×3W 外置功放输出。

## 6. 触摸与传感
- 触摸接口：I2C（2 路），支持电容触摸输入。
- 传感接口：GPIO/PWM/I2C/SPI/UART 组合，支持灯效、伺服、电机驱动。

## 7. 通信与连接
- 无线：Wi‑Fi 6 + BLE 5.2。
- 有线：千兆以太网（可选）。
- 传输：USB 3.2 Gen1 ×2，USB-C（PD 3.0）。

## 8. 供电与功耗
- 电池：内置 18650 电池组供电（主控）。
- 充电：支持 PD 充电与电池管理（BMS）。
- 功耗：待机 ≤ 5W，峰值 ≤ 25W。

## 9. 调试与量产接口
- 调试口：UART 1 路，JTAG（可选）。
- 量产测试：USB 工装下载与自检接口。

## 10. 可靠性与安全
- ESD：接触放电 ≥ 8kV。
- EMC：满足 CE/FCC 认证标准。
- 环境：0–40°C 正常运行。

## 11. 接口定义（逻辑）
- 显示：MIPI-DSI → 表情屏。
- 灯效：PWM/GPIO → RGB LED 驱动。
- 音频：I2S → 功放与麦克风阵列。
- 触摸：I2C → 触摸传感器。
- 模块通信：USB-C / Wi‑Fi / BLE。

## 12. 备注
- 具体 pin 脚与时序参数以硬件原理图与芯片手册为准。
