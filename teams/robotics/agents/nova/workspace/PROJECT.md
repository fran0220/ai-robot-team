# PROJECT.md - 情感交互机器人 + 围棋模块

## 项目概述

**产品定位**：以情感交互机器人为本体，围棋专业模块为首发扩展，构建模块化桌面智能陪伴生态系统。

### 差异化价值
- **情感AI实体化**：表情灯光、耳朵动作、触觉反馈多模态融合
- **专业围棋生态**：赛事级对弈、考级评测、监考管理完整闭环
- **模块化扩展**：开放式架构支持后续棋类、游戏、教育场景

### 目标用户
- 家庭娱乐与成长陪伴
- 围棋培训机构专业教学
- 线上围棋赛事与考级认证
- 桌面智能助手日常互动

---

## 系统架构

### 双机协同形态

| 模块 | 职责 | 推荐配置 |
|------|------|----------|
| **陪伴主控机器人** | 语音交互、情感表达、UI显示、监考管理 | RK3587 或同级（≥6 TOPS NPU） |
| **围棋功能模块 (GBM-19)** | 棋盘识别、AI对弈、机械臂自动落子 | 无独立算力，依赖主控计算 |

### 核心设计原则
1. **职责清晰**：围棋AI计算与机械控制在GBM-19完成，主控专注交互与管理
2. **本地优先**：关键功能离线可用，联网仅用于更新与云端增强
3. **安全隐私**：最小化采集、边缘推理、数据可控
4. **标准化接口**：机械、电气、软件三层标准化

---

## 核心功能模块

### 1. 情感交互系统（主控）
- 语音交互：本地唤醒 + 云端深度理解
- 表情动作：4路伺服电机，LED灯环
- 情感映射：语音情感分析驱动表情

### 2. 围棋专业系统（GBM-19）
- 视觉识别：99.5%+准确率，支持多种材质
- AI引擎：自研围棋算法，实时评估
- 机械执行：精度≤1.0mm，支持复盘演示

### 3. 监考反作弊系统
- 身份验证：人脸识别 + 持续验证
- 棋谱AI分析：多引擎吻合度检测
- 行为监测：视觉、时间、设备多维度
- 三级风险判定：低/中/高风险分级处理

---

## 关键技术指标

| 指标 | 目标值 |
|------|--------|
| 棋子识别准确率 | ≥99.5% |
| 落子定位精度 | ≤±1.0mm |
| 语音唤醒响应 | ≤300ms |
| 棋局变化检测延迟 | ≤1.0秒 |
| 安全响应时间 | ≤100ms |
