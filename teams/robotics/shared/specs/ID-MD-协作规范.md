# ID-MD 协作规范

## 设计交接流程

```
@idra (ID 设计) ──────────────────────────→ @mech (MD 设计)
        │                                         │
        ├─ 概念图 (designs/concept/)              ├─ 结构件 (cad/)
        ├─ CMF 方案 (designs/cmf/)               ├─ 装配图
        └─ 设计规格 (docs/)                      └─ DFM 报告
```

## @idra 交付物要求

### 1. 概念图
- [ ] 主要视角（3/4、正面、侧面）
- [ ] 标注关键外形尺寸
- [ ] 标注功能区域（屏幕、按键、散热口）

### 2. CMF 方案
- [ ] 推荐材料（ABS/PC/金属）
- [ ] 壁厚建议
- [ ] 表面处理（喷漆/电镀/IMD）

### 3. 设计规格文档
- [ ] 设计理念说明
- [ ] 尺寸约束
- [ ] 不可更改的外观特征

## @mech 设计约束

1. **外观一致性**：结构设计不得改变 ID 定义的外观
2. **壁厚**：遵循 ID 指定的壁厚范围
3. **分件线**：分件位置需与 ID 确认
4. **开口位置**：散热口、接口位置遵循 ID 设计

## 协作检查点

| 阶段 | @idra | @mech |
|------|-------|-------|
| 概念确定 | ✅ 输出概念图 | 📖 评审可行性 |
| CMF 确定 | ✅ 输出 CMF 方案 | 📖 确认材料可用性 |
| 结构设计 | 📖 审核外观一致性 | ✅ 输出结构件 |
| DFM 审查 | 📖 确认外观影响 | ✅ DFM 报告 |

## 共享目录结构

```
/root/multiagent/team/shared/
├── designs/          # @idra 产出
│   ├── concept/      # 概念图
│   ├── cmf/          # CMF 方案
│   └── renders/      # 渲染图
├── cad/              # @mech 产出
│   ├── housing/      # 外壳
│   ├── mechanism/    # 机构
│   └── assembly/     # 装配
└── specs/            # 规格文档
```

## 冲突解决

当结构需求与外观冲突时：
1. @mech 提出问题和替代方案
2. @idra 评估外观影响
3. @nova 协调最终决策
