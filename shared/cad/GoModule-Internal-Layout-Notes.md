# Go Module 内部空间布局说明 (v1.0)

## 1. 总体设计参数
- **外部尺寸**: 620mm x 420mm x 85mm
- **棋盘兼容性**: 预留 505x505x8mm 沉台，适配标准 45-50cm 棋盘
- **材料/工艺**: 主体为哑光白 ABS (注塑)，金属点缀采用铝合金 6061

## 2. 内部组件布局预留
### 2.1 步进电机空间
- **位置**: 位于底座右后方，机械臂安装座正下方。
- **预留容积**: 100mm x 100mm x 75mm
- **规格支持**: 适配 NEMA 17/23 步进电机（带减速器）。
- **固定方式**: 4x M5 螺栓固定至加强筋座。

### 2.2 主控板 (PCB) 空间
- **位置**: 位于底座前部左侧，显示屏模块后方。
- **预留尺寸**: 140mm x 100mm x 30mm
- **通风设计**: 右侧对应外壳设有 6 组 3x20mm 散热格栅，预留 40mm 风扇位。
- **IO接口**: 后部对应 40x10mm 切口。

### 2.3 摄像头与视觉识别空间
- **位置**: 机械臂末端执行器预留安装孔。
- **线缆通道**: 
    - 机械臂内部预留 10-12mm 走线槽。
    - 机械臂底座至主控板预留线缆导向柱。

### 2.4 电源模块
- **位置**: 位于底座右侧中部，远离敏感 PCB 以减少电磁干扰。
