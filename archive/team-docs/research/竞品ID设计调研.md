# 竞品 ID 设计调研｜儿童机器人市场

时间：2026-02-03

## 调研对象总览

- Anki Cozmo / Vector

- Kiki

## 1. Anki Cozmo / Vector

**图片/外观参考**
- Cozmo 图片：Wikipedia 词条图片（白灰机身、红色点缀、黑色方形“脸屏”）
  - https://en.wikipedia.org/wiki/Cozmo
- Vector 图片：RobotsGuide 页面（照片来源 Anki）
  - https://robotsguide.com/robots/vector

**造型语言**
- 小型履带式“头+躯干”结构，整体圆润中带一点机械切面。
- 明显“挖掘臂/叉臂”动作部件，玩具感强。
- 头部略大于身体比例，强化表情输出与“角色化”印象。

**材质运用**
- 硬质塑料外壳（白/灰/黑），局部橡胶履带。

**配色方案**
- 主色：白/灰；辅色：黑；点缀：红（Cozmo）。
- Vector 更偏黑灰低饱和，成人向家用设备感。

**表情设计**
- 黑色 OLED/LCD 屏幕做“脸”，高度动态表情。
- 通过眼睛动画和“眉”形变产生情绪张力。

**尺寸比例**
- Cozmo 小体量，掌上级别。
- Vector 体量略小但更“桌面陪伴”定位（RobotsGuide 提供尺寸：宽 6 cm / 高 7 cm / 长 10 cm）。

**儿童友好设计**
- 低重心+履带稳定；外壳圆角；动作节奏拟人但安全。

## 2. LOVOT（日本情感机器人）

**图片/外观参考**
- RobotsGuide 页面（含照片来源标注）
  - https://robotsguide.com/robots/lovot
- 官方技术页（外形结构示意）
  - https://lovot.life/en/technology/

**造型语言**
- 大头、小躯干、圆滚体型，仿生但非具体动物。
- 强烈“婴儿/幼宠”比例（头大、身体短胖）。

**材质运用**
- 软触感外皮（织物/仿毛）、内层硬壳结构。
- RobotsGuide 材料说明：聚碳酸酯、聚酯/聚乙烯皮肤与服装、玻璃、PU、硅胶。

**配色方案**
- 原生色多为米白/浅色系，配合衣物定制。
- 通过“衣服/配件”实现颜色和个性化。

**表情设计**
- 双 LCD 眼睛，多层光学投影形成“瞳孔深度感”。
- 眼皮/瞳孔运动为主，配合声效/身体动作增强情绪。

**尺寸比例**
- RobotsGuide：宽 28 cm / 高 43 cm / 深 26 cm，重量约 4.3 kg。

**儿童友好设计**
- 软触表皮、可抱持的圆润体型。
- 轮子可收回设计，减少衣物摩擦与安全隐患。

## 3. Kiki（Zoetic AI 宠物机器人）

**图片/外观参考**
- CNET 报道图（CES 2019）
  - https://www.cnet.com/tech/computing/kiki-the-pet-robot-wants-to-be-your-best-friend-and-doesnt-shed-any-fur/

**造型语言**
- “宠物化”设计，小动物体态+拟人脸部。
- 头部圆滑，面部大面积显示区，整体像桌面宠物。

**材质运用**
- 信息有限，偏硬质外壳与可动结构。

**配色方案**
- CNET 描述为“sleek design”，视觉偏简洁科技感。

**表情设计**
- 大型屏幕“动漫眼”，强调可爱与互动。

**尺寸比例**
- 头部比例较大，突出表情与注意力抓取。

**儿童友好设计**
- 通过“宠物化”降低科技感与距离感。

## 4. 小度智能屏（儿童/家庭场景）

**图片/外观参考**
- 砍柴网体验文：小度在家智能屏 X8（白色机身 + 8 英寸屏）
  - https://m.ikanchai.com/pcarticle/331284

**造型语言**
- “屏幕为主体”的极简矩形，底座略厚形成“台座”。
- 偏家居电器而非玩具机器人。

**材质运用**
- 白色塑料机身，正面灰色织物扬声器面板。

**配色方案**
- 白色机身 + 灰色布面，低刺激、家居化。

**表情设计**
- 以屏幕 UI 为“表情/内容载体”，弱拟人化。

**尺寸比例**
- 屏幕占比高，音箱区域较小（文章提到 8 英寸屏）。

**儿童友好设计**
- 儿童模式、童脸识别、时长/距离控制（交互层面）。
- 外观上圆角+大屏易读。

## 5. 天猫精灵 儿童智能音箱 TG_A1

**图片/外观参考**
- 我爱音频网拆解报告（含外观图与细节）
  - https://www.52audio.com/archives/19565.html

**造型语言**
- “小动物化”玩偶体型：猫脸+领结+尾巴。
- 拟人/拟宠特征明显（脸部发光、领结作为交互区）。

**材质运用**
- ABS/PC 外壳，食品接触级硅胶（文中标注）。
- 头部硅胶套 + 发光透光片。

**配色方案**
- 常见为浅色主体，柔和配色营造亲和力。

**表情设计**
- 通过“猫脸发光面板”营造表情/状态反馈。
- LED 光效作为情绪提示。

**尺寸比例**
- 类玩偶尺寸，头部比例偏大，强调“脸”。

**儿童友好设计**
- 硅胶材质、柔和光照；底部防滑垫。
- 物理按键集中在领结位置，操作直观。

## 6. 科大讯飞 阿尔法蛋（大蛋）

**图片/外观参考**
- OFweek 测评（外观描述：鸡蛋体型、黑色面板）
  - https://mp.ofweek.com/ee/a645673824856

**造型语言**
- “蛋形体态”高度圆润，几乎无尖角。
- 正面黑色圆角矩形面板形成“脸”。

**材质运用**
- 白色抛光塑料外壳（文中描述“珠圆玉润”）。

**配色方案**
- 白色主体 + 黑色面板，对比强，科技感清晰。

**表情设计**
- 屏幕/黑色面板为脸部区域，强调“正面中心视觉”。

**尺寸比例**
- 高约 26 cm，直径约 21 cm（文中数据）。
- 上大下稳，重心低。

**儿童友好设计**
- 全圆润曲面与光滑触感；底部防滑脚垫。

**图片/外观参考**
- 官方产品页
  - https://us.keyirobot.com/pages/loonadetail

**设计要点**
- “小狗体态 + 屏幕眼睛”，强情感陪伴形象。

## 设计趋势总结

1. **大眼/屏幕表情成为主流**
   - Cozmo/Vector、Kiki、Loona、EMO 均以屏幕表情作为情绪核心。
   - “眼睛”是第一注意力焦点，角色化显著。

2. **圆润与软触材质提升安全与亲和**
   - LOVOT、阿尔法蛋、天猫精灵儿童版强调圆润和软材质。
   - 软触/织物/硅胶增强“可抱、可摸”的友好感。

3. **宠物化/拟生化造型更受儿童欢迎**
   - Kiki、Loona 采用宠物体态，能降低“机器感”。
   - 相比纯屏幕设备，更具陪伴感。

4. **配色趋向低饱和或可换装定制**
   - 白色/浅色底 + 柔和点缀更符合家居与儿童安全感。
   - LOVOT 通过衣物定制实现个性化。

5. **儿童版设备常采用“玩具化符号”**
   - 天猫精灵：猫脸、领结、尾巴。
   - 强符号化元素帮助建立“伙伴/玩具”属性。

## 设计建议（给 @idra）

1. **优先考虑“表情核心”布局**
   - 让“眼睛/脸”成为第一视觉焦点，尺寸尽量放大。
   - 表情语言简洁、可爱、易识别。

2. **体态优先圆润、重心低**
   - 大头小身、短肢体，提升亲和力与稳定性。
   - 避免尖锐结构，保证儿童安全。

3. **材质分层：硬壳 + 软触区域**
   - 触摸区域用硅胶/织物，降低冷硬感。
   - 软触区域可成为“互动反馈点”。

4. **配色体系：低饱和主色 + 高识别点缀**
   - 主色以白/米/浅灰，点缀用亮色（橙、红、蓝）。
   - 色彩层级少，避免杂乱。

5. **宠物化符号有利于情感连接**
   - 耳朵、尾巴、领结等元素可增强“生命感”。
   - 但需避免过度拟真动物，以免削弱品牌辨识度。
