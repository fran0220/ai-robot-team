# 围棋模块结构设计硬件评审报告 (v2)
**评审人**: @jarvis (硬件负责人)
**日期**: 2026-02-04
**评审对象**: @mech 设计的 Go Module 结构件及布局

## 1. 电机与传感器布局 (Risk: High)
*   **触达范围失配**: 这是目前最严重的问题。根据 `layout-notes.md` 第 13 行提到的 220mm 臂长，配合 CAD 中底座在 (240, 190) 的位置，机械臂无法覆盖 475x475mm 棋盘的全部区域。
    *   **计算**: 触达棋盘中心需 ~306mm，触达远角需 ~640mm。当前设计会导致“触及不到”死角。
*   **传感器选型**: 棋盘下方 19x19 的霍尔阵列（Hall Matrix）方案在 Z=74mm（棋盘槽底）与 Z=3mm（腔体底）之间的 70mm 空间内排布空间充裕，但需考虑棋子磁性强度对 PCB 感应距离的要求。

## 2. PCB 空间与电气布局 (Status: Pass)
*   **空间估算**: 内部有效空间约为 614mm x 514mm x 70mm。对于集成 RK3588 的主控板和 12V/24V 电源模块绰绰有余。
*   **接口位置**: 建议在 CAD 中明确 USB-C PD 接口和网络接口的开孔，目前 Z=20mm 处的特征疑似为显示屏/接口预留。

## 3. 散热设计 (Risk: Medium)
*   **散热路径**: 说明书中提到的“右侧散热孔”适合电机驱动。但主控 SoC（计算围棋算法）通常位于中心或左侧，热量易积聚。
*   **建议**: 在主控 PCB 上方预留散热片高度，并在外壳底部增加进风口，形成对流。

## 4. 机械臂精度 (Status: Follow-up)
*   **精度要求**: ≤±0.5mm 的精度不仅取决于电机编码器，还取决于减速机（建议谐波或高精度行星）和整体刚性。
*   **材料风险**: 外壳采用 ABS/PC 塑料，若机械臂底座直接固定在塑料上，长期运行会产生疲劳变形。必须确保机械臂通过金属支架直连底部的配重钢板。

## 5. 装配与维护 (Status: Pass)
*   **维护性**: 结构显示为上下壳分体。建议增加底部检修盖板，方便在不拆卸棋盘的情况下更换传感器 PCB。

## 6. BOM 成本影响 (Status: Neutral)
*   **结构成本**: 620x520mm 的大型注塑件模具费用较高，初期建议采用 CNC铝合金或 3D 打印框架 + 吸塑外壳以降低样机阶段成本。
*   **电机成本**: 为达到 0.5mm 精度，电机成本占比较大，需与 @sage 核对器件选型。

---
**评审结论**: **拒绝 (Reject)** - 需解决臂长覆盖范围的几何冲突后重新提交。
