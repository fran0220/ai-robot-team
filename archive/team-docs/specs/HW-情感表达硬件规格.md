# 情感表达硬件规格

## 1. 表情屏
- 尺寸：4.0–4.5 英寸。
- 分辨率：800×480 或以上。
- 亮度：≥ 400 nits，抗环境光干扰。
- 显示内容：
  - 表情动画（开心/难过/思考/鼓励等）。
  - 状态信息（联网、充电、学习模式）。

## 2. LED 灯效
- 位置：头部光环 + 底座光环。
- 数量：16–24 颗可编程 RGB LED。
- 支持效果：
  - 呼吸灯（待机/思考）。
  - 闪烁灯（提示/警告）。
  - 渐变灯（情绪变化）。
- 控制接口：PWM/GPIO，支持多路独立控制。

## 3. 扬声器
- 规格：2×2W 或 1×3W 全频扬声器。
- 频率响应：200Hz–15kHz。
- 音质要求：清晰童声与 TTS 播放，无明显失真。
- 失真要求：THD < 5%。

## 4. 触摸传感器
- 位置：头顶、脸颊、背部三处。
- 类型：电容式触摸。
- 灵敏度：触摸响应 < 50ms。
- 交互动作：
  - 头顶：抚摸触发“开心/鼓励”。
  - 脸颊：触发“害羞/亲昵”。
  - 背部：触发“安抚/轻声模式”。

## 5. 机械表情与动作（可选）
- 耳朵 2 轴伺服控制，支持上下/左右动作。
- 头部微摆动，增强情绪表达。

## 6. 外观与安全要求
- 表面材质：儿童安全材料（RoHS/REACH）。
- 结构：无尖锐棱角，触摸区域防夹手设计。
- 可维护：模块化拆装，便于售后维护。
